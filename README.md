# Website Seksi Pengendalian dan Penanganan Sengketa

Web-based archive management system developed as part of the **MBKM MITRA USU Program, Even Semester 2024/2025**, in collaboration with **Kantor Pertanahan Kota Medan, Badan Pertanahan Nasional**.

The system was developed to support the management and digitization of archives related to dispute handling and administration.

---

## 📌 Overview

This project is a web-based information system developed to support the activities of the **Seksi Pengendalian dan Penanganan Sengketa** at Kantor Pertanahan Kota Medan.

The application provides a structured system for managing information and administrative data related to dispute handling, replacing manual or less structured processes with a centralized web-based system.

---
